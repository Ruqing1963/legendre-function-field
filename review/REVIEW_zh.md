# 审稿报告：Zenodo v5

**论文：** Ruqing Chen，*The Geometry of Prime Vacuums: Legendre's Conjecture in Function Fields via Monodromy and Chebotarev Density*，Zenodo，2026-02-20，DOI [10.5281/zenodo.18705744](https://doi.org/10.5281/zenodo.18705744)。审阅文件为 `paper/archive/Legendre_v5_zenodo.tex`。

**结论：大修。** 主定理的渐近结论是对的，但不是新结果。三处证明有漏洞，显式阈值没有得到证明。以下问题已在修订稿 `paper/Legendre_FF_v6.tex` 中全部修正。

## 一、论文内容概述

对首一、无平方因子、次数为 d 的 f ∈ F_q[t]，并要求 char F_q > 2d，文章考虑"勒让德区间" I_f = {f² + s : deg s ≤ d}。文章声称：

- N_irr = q^{d+1}/(2d) + O(q^{d+1/2})；
- 当 q > (8d)^{2d+6} 时 N_irr ≥ 1。

证明路线是：S_{2d} 单值群，加上有效 Chebotarev 定理，再加上 Katz 的 Betti 数界。

## 二、主要问题

**M1 主定理是已知结果的特例。** Bank–Bary-Soroker–Rosenzweig（Duke Math. J. 164 (2015)，定理 2.3 与推论 2.4）已对一切短区间 f + F_q[t]_{≤m}（1 ≤ m < k）给出了任意分解型的计数。令 k = 2d、m = d，并把 f 换成 f²，即得到 v5 的主定理。他们的结果对所有奇数 q 成立，不需要无平方因子条件，也不需要 p > 2d。他们的摘要还特别提到突破了 ε = 1/2，而这正是勒让德区间的情形。v5 只把这篇文章当作"可能得到更好常数"的参考，这是对已有工作的误述。

**M2 本原性证明（命题 2.3）有漏洞。** 文中引用了"非本原 ⇔ F = g∘h"。这个等价只对 Gal(G(t) − x / K(x)) 成立，其中 x 是超越元，并且只出现在常数项里。它对域上任意多项式的 Galois 群并不成立。v5 没有把 a₀ 单独分离出来，所以不能直接套用这个等价。最后一步的维数论证把 g 的系数当成 A^n 中的自由参数，但这些系数实际上属于 F̄_q(a) 的代数扩张。结论本身是对的，但这个证明不成立。

**M3 对换的证明（命题 2.4）有错误。**

- 文中断言判别式在 a = 0 附近的分支是 {P(α_j) = 0}，这里忽略了一次项 P′(α_j)u。当 P(α_j) = 0 而 P′(α_j) ≠ 0 时，二重根实际上分裂成两个根，所以分支认错了。
- 参数 a_d 被漏掉了。
- 在特征 p 下直接引用 Picard–Lefschetz，没有说明为什么适用。
- 文中说"需要 p > 2d 才能保证 f′(α_j) ≠ 0"，这是错的：只要无平方因子就够了。

**M4 有效 Chebotarev 定理（定理 3.2）的表述有误。** 误差项用置换层 π_*Q̄_ℓ 的 Betti 数来写。但 Frobenius 在这个层上的迹只数不动点，也就是一次因子的个数，检测不到 2d-循环。要数 2d-循环，需要用到 S_{2d} 中在该共轭类上取值非零的全部不可约特征，也就是 2d 个钩形特征。文中引用的"Katz 1988, Thm 9.2.6"也不是有效 Chebotarev 定理。

**M5 显式阈值 (8d)^{2d+6} 没有证明。** 文中把 B(F) ≤ N(2δ+1)^n 归于 Katz 2001 的定理 12。但该定理处理的是 Artin–Schreier 层和 Kummer 层 L_ψ(f) ⊗ L_ρ(G)，不涉及有限覆叠的推出层。Katz 对一般相容系统给出的界（定理 6、9）也不是显式的。

**M6 误差项混淆。** 第 4 步把 Chebotarev 定理中未指明的 O(q^{n−1}) 项替换成了 D(F_q) 的 Lang–Weil 点数。这两个量不是同一个东西。而且第 3 步已经说明 N_irr = N_irr°，判别式上的点数本来就用不到。

## 三、次要问题

1. 式 (4.1) 中的 j_! 应改为 j_*。另外第 4 节在全文的证明中没有被用到。
2. Bary-Soroker 的文献信息有误：应为 Proc. AMS **137** (2009), 73–83。而且该文是在 PAC 域上做的，不是有限域上的 Chebotarev 方法。
3. AGLV 条目的键名写的是 1993，年份却是 1988，前后不一致。
4. 有七条参考文献在正文中没有被引用。
5. 正文里出现了"earlier versions erroneously…"之类的版本历史说明，应移到修订说明中。
6. 只凭 q ≤ 11、d ≤ 2 的三个例子就推断"对一切 q、d 都有 N_irr ≥ 1"，证据明显不够。
7. 第 1.2 节（"Titan Project"背景）夸大了本文与导子刚性系列论文之间的联系。
8. Dixon–Mortimer 的定理编号看起来引错了：v5 引的是 3.3E（素数循环版本）；"本原 + 对换 ⇒ S_n"在 3.3A。

## 五、修订稿的处理

- **定理 A：** 在 p > 2d 时证明 G_geom = S_{2d}，并且**去掉了无平方因子假设**。新证明的本原性部分是先分离出 a₀ 再用 Lüroth 定理；对换部分是显式构造一条恰有一个二重根的纤维，再用离散赋值环上的惯性引理。
- **定理 B：** 精确恒等式 2d·N_irr = #W(F_q) − E。其中 W 是显式的扭根簇，次数不超过 (d−1)!，且 0 ≤ E < q^{d+1}/(q−1)。这完全取代了上同调形式的 Chebotarev 步骤。
- **定理 C：** 用 Cafure–Matera 的显式 Lang–Weil 估计（FFA 12 (2006)，定理 7.1）得到严格的显式阈值。例如 d=4 时为 q > 1.65×10⁴，d=5 时为 q > 7.3×10⁶。另给出一条经 Katz Betti 数界与 Deligne 定理的独立途径。
- **与 Sawin (2021) 的比较：** v6 初稿没有引用 Sawin 的 [Duke Math. J. 170 (2021)](https://arxiv.org/abs/1809.05137)，现已补上。Sawin 的推论 4.7 在短区间上给出带显式常数、接近平方根的抵消。v6 的命题 5.5 由此推出：当 p > 2d 时，|2d·N_irr − q^{d+1}| ≤ 6(2d+2)^{3d−1} q^{d/2+1} + dq + d²，对应阈值约为 (2d+2)^6。对每个 d ≥ 5，这都优于定理 C；定理 C 只在 d = 4 时仍是已知最好的界。Sawin 研究的有序根簇就是文中的根簇 V，所以定理 B 是他的点数计算的扭形式，思路并不新。
- **定理 D：** d ≤ 3 时给出闭式公式，对一切允许的 q 都有 N_irr ≥ 1。其中 d=3 的情形与 Kuz'min 关于前两个系数给定的不可约多项式计数公式一致。
- **数值实验：** 对 d ≤ 6 做了系统的精确计数，与定理 D 零不符。通过枚举 F_{q^{2d}} 验证了扭簇恒等式。对小 q 穷举了全部 f，没有发现不含不可约多项式的区间。
